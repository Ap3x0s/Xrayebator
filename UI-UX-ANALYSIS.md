Дата: 2026-08-12

---

## 1. Что за приложение

**Xrayebator Desktop** — программа для управления VPS-серверами с Xray Reality VPN (обход DPI-цензуры). Экран 1: список серверов. Экран 2: развёртывание на новый VPS (SSH → install → quickstart). Экран 3: ключи (vless:// ссылки, QR-код, subscription URL). Экран 4: настройки сервера (профили, протоколы, обновление/удаление).

Стек: React 19, HeroUI, Tailwind 4, lucide-react, i18n (ru/en/zh), Electron. Хранилище: electron-store, пароль не сохраняется.

## 3. Что сделано хорошо (сохранить)

### 3.1. Тема подходит продукту
Палитра GitHub-dark (#0d1117 / #161b22 / #21262d, акцент #58a6ff) — эталон для dev-инструментов и security-утилит. Пользователь (технический, «ставит VPN на VPS») сразу узнаёт язык GitHub/VSCode. Менять не нужно. Светлой темы нет — и не нужно.

### 3.2. Контраст в тёмной теме — отличный
Реальный расчёт: базовый текст **16:1**, вторичный **9.6:1**, приглушённый **4.9:1**, акцент **7.5:1**, зелёный/жёлтый **7.5:1**, красный **5.7:1** — всё проходит нормы читаемости.

### 3.3. Семантические токены
Цвета заданы один раз в `tokens.css` (`--bg-0/1/2`, `--text-0/1/2`, `--accent`, `--success`, `--warning`, `--danger`), в компонентах цветов хардкода нет. Правильная система.

### 3.4. Иконки — SVG, не эмодзи
lucide-react + country-flag-icons (флаги на Windows не рендерятся эмодзи-кодом — решение с fallback верное).

### 3.5. Процесс развёртывания — лучшая часть UX
- 7 шагов (SSH → ОС → загрузка → установка → бинарник → quickstart → сохранение) с состояниями ожидание/активно/готово.
- Живой журнал консоли.
- Пульсирующая точка активного шага, анимация появления при завершении.
- Подпись каждого шага — пользователь всегда знает, что происходит.

### 3.6. Удаление — с подтверждением
Удаление сервера, профиля, Xrayebator с сервера — везде диалог с описанием последствий.

### 3.7. Пароль не сохраняется
В UI прямо сказано «Пароль нигде не сохраняется». Правильный компромисс для security-продукта.

### 3.8. Умные мелочи
- Предпросмотр имён создаваемых профилей (name, name-2, name-3…) с лимитом 6 + «+N».
- Бейдж «Рекомендуем» на XHTTP.
- Защита HAPP-профиля от удаления.
- Подсказки протоколов понятными сценариями («игры, видеозвонки», «мессенджеры»).

## 4. Проблемы и как их исправлять

### 🔴 P0 — Срочно

#### 4.1. «Назад» во время развёртывания может сломать сервер — **исправляем**
**Простыми словами:** пока идёт установка/обновление на сервере, кнопка «Назад» всё ещё активна. Если нажать — процесс оборвётся на полушаге, сервер может остаться сломанным. **Именно так сервер и сломался в реальности.**

**Как исправить:** во время долгих операций блокировать «Назад», а если человек всё же пытается уйти — показывать предупреждение «Прервать развёртывание? Сервер может остаться в нерабочем состоянии». Правило на все долгие операции: либо нельзя уйти, либо спрашиваем.

---

### 🟠 P1 — Важное

#### 4.2. Шрифты объявлены, но не подключены — **исправляем**
**Простыми словами:** в настройках написано, что приложение использует шрифты Inter и JetBrains Mono, но самих файлов шрифтов в программе нет. На Windows она рисует обычный системный текст (Segoe UI). Из-за этого интерфейс выглядит «дёшево» и не как задумано.

**Как исправить:** положить шрифты в приложение (`@fontsource/inter` + `@fontsource/jetbrains-mono`) и импортировать. Это самый заметный визуальный апгрейд за минимальные усилия.

#### 4.3. Кнопка «Обновить» качает самую сырую ветку с GitHub
**Простыми словами:** «Обновить» всегда тянет версию под названием «experimental» (экспериментальная, самая неотлаженная). GitHub-версия к тому же отставала — из-за этого приложение обновлялось на более старое и ломалось.

**Как исправить:** сделать так, чтобы «Обновить» гарантированно не откатывало на старое/сырое: обновлять из свежих файлов, встроенных в приложение, либо хотя бы не хардкодить experimental.

#### 4.4. QR-окно не закрывается клавишей Esc — **добавить отклик**
**Простыми словами:** окно с QR-кодом открывается и закрывается только кликом по фону. Люди-«клавиатурники» не смогут его закрыть. В остальном с QR всё работает нормально.

**Как исправить:** добавить закрытие по Esc, больше ничего не трогать.

---

### 🟡 P2 — Желательное

#### 4.5. Трей-иконка — прозрачный пиксель — **отложено**
**Простыми словами:** иконка программы в системном трее (рядом с часами) — пустой прозрачный квадрат 1×1. В Windows выглядит как мусор.

**Как исправить:** настоящая иконка 16/32px (щит/молния). Решаем, что пока не делаем, держим в уме.

#### 4.6. Подсказка, куда вставлять ключи — **делаем**
**Простыми словами:** на экране ключей заголовок «Ключи для HAPP» для новичка непонятен. Достаточно добавить подсказку, что ключи работают не только в HAPP: «Откройте ссылку в HAPP, Hiddify или любом другом VPN-клиенте».

**Как исправить:** добавить на экран ключей одну поясняющую строку с перечислением приложений.

#### 4.7. Зелёная точка «онлайн» без проверки — **делаем**
**Простыми словами:** на карточке сервера всегда горит зелёный индикатор, будто сервер работает прямо сейчас. Но приложение его не проверяет — сервер может быть выключен, а точка всё равно зелёная.

**Как исправить:** либо реально проверять доступность (стучаться) и красить точку по факту, либо убрать её, чтобы не вводить в заблуждение.

#### 4.8. Журнал развёртывания: авто-прокрутка вниз — **делаем**
**Простыми словами:** в окне развёртывания идёт текст процесса. При длинном выводе свежие строки уходят за нижний край — пользователь должен вручную листать вниз, чтобы видеть текущий шаг.

**Как исправить:** добавить авто-прокрутку журнала на новую строку (как в терминалах). Удлинять само окно не стоит: окно резиновое, и автоматическое изменение его размера во время вывода будет дёргать интерфейс и спорить с пользователем, который сам растянул окно. Автоскролл решает ту же проблему без побочных эффектов.

## 6. Визуальные не-критичные улучшения

1. **Подключить шрифты** (п.4.2) — сразу даст «дорогой» вид.
2. **Лёгкая глубина**: едва заметное свечение сверху фона, тени у карточек при наведении. Аккуратно, чтобы не сломать контраст.
3. **Микроанимация перехода между экранами** (плавное появление 200мс) — сейчас экраны переключаются мгновенно.
4. **Метаданные сервера**: флаг + страна + ОС + число маршрутов уже есть — собрать в аккуратную «статус-строку» вместо кучи чипов.

3. 🟠 Разобраться с источником «Обновить», чтобы не откатывало на старое/experimental.
